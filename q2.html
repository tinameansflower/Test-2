How the Action attribute works

... in my own words

The action attribute tells the program where to send data collected from the user-submitted form. For example, when a user inputs data and submits the form (be it a survey or login info), the browser collects the input data and sends it as an HTTP request. This is where the "action" attribute comes in, the action specifies where the input data should be send to where the specified URL will then get and process the collected data.
